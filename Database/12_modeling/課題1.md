課題:SQLクエリで以下の式を実行した時の結果を答えてください。

### SELECT NULL = 0;

```
NULL
```

NULLを含む比較は、trueでもfalseでもなくunknown(不明)とされるため、SQLではNULLと返される


### NULL = NULL (以下、SELECT部分を省略)

```
NULL
```

未知な値と未知な値は等しいか？になるので判断できない= NULL(=unknown)になる

### NULL <> NULL

```
NULL
```

### NULL AND TRUE

```
NULL
```
両方がTRUEではなく結果が不明のためNULL

### NULL AND FALSE

```
FALSE
```
片方がFALSEなら即FALSEだから

### NULL OR TRUE

```
TRUE
```
片方がTRUEなら即TRUEだから

### NULL IS NULL

```
TRUE
```
IS演算子はNULLを特別に判定できる

### NULL IS NOT NULL

```
FALSE
```

NULLはNULLなのでIS NOT NULLはFALSE
